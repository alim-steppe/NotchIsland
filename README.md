# Notch Island

Свой «динамический островок» вокруг выреза MacBook. Наводишь курсор на вырез, и островок раскрывается. В нём 4 вкладки:

| Вкладка | Что умеет |
|---|---|
| 📅 Календарь | Встречи на сегодня и завтра из выбранных аккаунтов, кнопка **«Войти»** для Google Meet / Zoom / Teams, бейджи «через 5 мин» / «Идёт». Встречи, от которых ты отказался, скрыты. |
| 🎵 Музыка | Обложка, трек, перемотка, пауза, следующий/предыдущий трек в Apple Music. |
| 🖼 Скриншоты | Последние скриншоты и скопированные картинки. Клик копирует, перетаскивание кидает файл в Telegram/Slack/Finder, двойной клик открывает. |
| ⚙️ Система | CPU с графиком, память, батарея, топ‑6 процессов (сортировка по CPU или RAM) с кнопкой «Завершить». |

В свёрнутом виде по бокам выреза появляются «ушки»: обложка и эквалайзер, когда играет музыка, и обратный отсчёт до встречи за 30 минут до начала.

---

## 1. Сборка (один раз, ~2 минуты)

Нужен **Xcode** (из App Store) или хотя бы Command Line Tools: `xcode-select --install`. Требуется macOS 14 Sonoma или новее.

```bash
cd ~/Downloads/NotchIsland      # путь к распакованной папке
chmod +x build.sh
./build.sh --install
```

Скрипт соберёт `NotchIsland.app`, положит его в «Программы» и запустит. В меню‑баре появится иконка, через неё открываются настройки и выход.

> Хочешь редактировать код в Xcode? Открой `Package.swift` (`open Package.swift`). Запускай всё равно через `./build.sh --install`: приложению нужен Info.plist с разрешениями, и при запуске прямо из Xcode доступ к календарю не сработает.

## 2. Разрешения (macOS спросит сама)

- **Календарь**: нажми «Разрешить».
- **Управление Music**: появится при первом запуске Music. Если отказал, включи вручную: Настройки → Конфиденциальность и безопасность → Автоматизация → Notch Island → Music.
- **Папка «Рабочий стол»**: нужна, чтобы видеть скриншоты.

После каждой пересборки macOS может спросить разрешения заново, потому что подпись локальная. Это нормально.

## 3. Подключение корпоративных Google‑календарей

1. **Системные настройки → Учётные записи интернета → Добавить → Google.**
2. Войди под рабочей почтой и включи только **«Календари»**. Так можно добавить сколько угодно аккаунтов.
3. В островке нажми ⚙️ (или иконку в меню‑баре → «Настройки…»).
4. Отметь галочками нужные **аккаунты**, а внутри них отдельные **календари**. Всё, что выключено, в островок не попадёт.

Ссылки на Google Meet подтягиваются из описания встречи автоматически.

## Если что‑то не работает

- **Ошибки при сборке**: скопируй вывод терминала и пришли мне, я поправлю.
- **Островок не появляется на Mac без выреза**: так и задумано, там вместо выреза будет капсула по центру меню‑бара.
- **Нет скриншотов**: проверь, куда они сохраняются (⇧⌘5 → «Параметры»). Островок читает эту папку автоматически, путь виден в настройках.
- **Автозапуск**: в настройках есть «Запускать при входе в систему».
